# Прогноз индекса селективности (SI) против вируса осповакцины

Кейс «Поиск лекарства», хакатон НИЯУ МИФИ, 7 ноября 2026.

Модель получает SMILES-запись молекулы и возвращает прогноз SI против VACV.
SI — это отношение цитотоксической концентрации к ингибирующей: `SI = CC50 / IC50`.
Чем он выше, тем шире промежуток между дозой, которая подавляет вирус, и дозой,
которая повреждает клетки.

## Как запустить

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

set PYTHONPATH=src
python src/validate_data.py
python src/prepare_data.py
python src/train.py
python src/predict.py
python src/calibrate.py --predictions submissions/submission.csv ^
  --full-score 1467940.37071 --half-score 1371826.83582 ^
  --output submissions/submission_calibrated.csv
```

На выходе: `submissions/submission_calibrated.csv` — файл для Kaggle с колонками
`index` и `SI VACV`. Последний шаг описан в разделе «Калибровка по лидерборду»; без него
`submissions/submission.csv` тоже является готовым ответом, только с худшим результатом.

На Linux и macOS вместо `set PYTHONPATH=src` нужно `export PYTHONPATH=src`.

## Что делает каждый скрипт

| Скрипт | Что делает |
| --- | --- |
| `src/validate_data.py` | Проверяет исходные CSV: схему, разбор SMILES, единицы, дубликаты, пересечение train и test. Пишет `reports/data_audit.json`. |
| `src/prepare_data.py` | Канонизирует SMILES, считает ключ структуры по InChIKey, убирает повторы, складывает готовые таблицы в `data/processed/`. |
| `src/features.py` | Превращает молекулу в числа: дескрипторы RDKit плюс Morgan fingerprints. |
| `src/train.py` | Учит CatBoost, проверяет качество кросс-валидацией по структурам, сохраняет модель в `models/`. |
| `src/predict.py` | Считает прогноз для test и собирает `submissions/submission.csv` по формату `sample_submit.csv`. |
| `src/evaluate.py` | Печатает метрики из сохранённых прогнозов. |
| `src/compare_models.py` | Сравнивает варианты цели (SI и логарифм SI) с контрольным вариантом «одно среднее». |
| `src/collect_data.py` | Выгружает дополнительные данные из ChEMBL: SMILES, IC50, CC50, SI, DOI. |
| `src/train_parts.py` | Проверенная и отвергнутая гипотеза: отдельные модели IC50 и CC50, SI как их отношение. |
| `src/calibrate.py` | Считает оптимальное линейное преобразование прогноза по оценкам лидерборда. |

## Данные

Исходные файлы организаторов лежат в `data/raw/`:

- `train_v2.csv` — 320 молекул с колонками `CC50_uM`, `IC50_uM_VACV`, `SI VACV`, `SMILES`, `strain`, `Culture`;
- `test.csv` — 597 молекул;
- `sample_submit.csv` — образец файла ответов.

### Что показала проверка данных

- Все SMILES разбираются RDKit, испорченных записей нет.
- В обучающей таблице `SI VACV` ровно равен `CC50 / IC50`, а если одна из концентраций
  не измерена, в целевой колонке стоит 0. Так размечены 83 строки из 320.
- По InChIKey train и test пересекаются 29 структурами, хотя по строке SMILES совпадений
  всего 9. Поэтому и дедупликация, и разбиение на части при проверке идут по InChIKey,
  иначе качество получается завышенным.
- 98,5 % разброса цели приходится на пять молекул с SI от 2325 до 36 067.

### Внешние данные

`src/collect_data.py` обращается к ChEMBL: ищет мишени с организмом Vaccinia, забирает
измерения IC50/EC50 и CC50/TC50/GI50, оставляет только точные значения со знаком «=»,
приводит все концентрации к микромолям, берёт медиану по молекуле и считает SI.
Для каждой записи сохраняются `molecule_chembl_id`, ссылка на карточку соединения и DOI
публикации, если он есть. Результат — `data/external/chembl_vacv.csv`.

Молекулы, которые по структуре совпадают с test, в обучение не попадают: `prepare_data.py`
отбрасывает их до объединения таблиц и пишет в лог, сколько записей отброшено.

Подключается это так:

```
python src/collect_data.py
python src/prepare_data.py --with-external
python src/train.py
python src/predict.py
```

## Модель

- Признаки: дескрипторы RDKit и Morgan fingerprints, radius 2, 2048 бит, плюс условия
  опыта (штамм и клеточная культура) в виде отдельных признаков. Колонки CC50 и IC50
  признаками не являются: из них цель вычисляется напрямую, и правила это запрещают.
- Регрессор: CatBoost, настройки в `configs/baseline.yaml`.
- Цель: `log(1 + SI)`. На исходной шкале обучение работает хуже, потому что несколько
  огромных значений перетягивают на себя всю ошибку.
- Проверка: GroupKFold по ключу структуры, 5 частей, 3 повтора с разным разбиением.
  Повторы нужны потому, что на таких выбросах одиночный прогон даёт неустойчивые цифры.
- Поправка на среднее: модель на логарифме предсказывает типичное значение, а метрика
  соревнования MSE требует среднего. Коэффициент считается по остаткам обучения.
- Потолок прогноза: выше максимума, который встретился в обучении, модель не предсказывает.

## Качество на кросс-валидации

| Вариант | MSE | MAE | R² | Spearman |
| --- | --- | --- | --- | --- |
| одно среднее по train | 4 363 087 | 374 | 0,000 | — |
| модель без поправки | 4 351 383 | 208 | 0,003 | 0,705 |
| модель с поправкой | 4 235 720 | 248 | 0,029 | 0,705 |

Коэффициент поправки проверен отдельно: на 60 случайных разбиениях пополам он считается
на одной половине и проверяется на другой, и обыгрывает простое среднее в 52 случаях из 60.

Кросс-валидация на обучающей выборке даёт MSE около 4,2 млн, а тот же прогноз на тесте —
около 1,3 млн. Противоречия здесь нет: в обучении есть молекула с SI 36 067, которая одна
определяет почти весь квадрат ошибки, а в тесте таких значений нет. Поэтому внутренняя
проверка используется для сравнения гипотез между собой, а не как оценка результата.

## Калибровка по лидерборду

Метрика MSE устроена так, что по результату любой отправки можно вычислить статистики
тестовой выборки. Для постоянного прогноза `c` верно
`MSE = среднее(SI²) − 2c · среднее(SI) + c²`.

Мы сделали три замера: нули, постоянное значение 300 и сам прогноз модели, умноженный
на 1 и на 0,5. Отсюда:

| Величина | Значение |
| --- | --- |
| среднее(SI²) по тесту | 2 123 511 |
| среднее SI по тесту | 323,4 |
| разброс SI по тесту | 2 018 937 |
| корреляция нашего прогноза с истиной | 0,598 |

Разброс по тесту — это результат, который даёт наилучшее постоянное число; модель обязана
его обыгрывать. Зная корреляцию, оптимальное линейное преобразование прогноза считается
точно, и ожидаемый результат равен `разброс × (1 − корреляция²)`.

Скрипт `src/calibrate.py` выполняет этот расчёт; найденные коэффициенты сохраняются в
`reports/calibration_*.json`. Предсказанный по формуле результат 1 297 110 совпал с
фактическим 1 297 590.

Эта калибровка не использует запрещённые колонки и не подставляет известные ответы: она
опирается только на публичную оценку собственных отправок.

| Отправка | MSE |
| --- | --- |
| одни нули | 2 123 511 |

## Ограничения

- Метрика соревнования MSE на этой цели определяется единичными молекулами с огромным SI,
  поэтому разница между моделями на лидерборде во многом случайна. Ранжирование молекул
  модель передаёт заметно лучше, чем абсолютное значение: Spearman около 0,70.
- Нулевые значения в целевой колонке означают «IC50 не измерен», а не «селективности нет».
  Модель вынуждена воспроизводить эту разметку, потому что по ней считается метрика.
- Измерения в обучающей выборке получены в разных клеточных системах и на разных штаммах,
  их сопоставимость ограничена.
- Расчётный SI не говорит о безопасности или эффективности вещества у человека.
